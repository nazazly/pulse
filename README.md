# Pulse (Multi-Sport & Esports Aggregator)

A unified sports and esports platform tracking schedules, live scores, and team profiles across CS2, Valorant, and Football.

## Core Features
- **Unified Match HUD:** Real-time scores and upcoming schedules normalized across multiple disciplines.
- **Dynamic Team Profiles:** Detailed rosters, recent form, and upcoming fixtures for tracked clubs (e.g., Manchester United, NAVI, Paper Rex).
- **Personalized Watchlist:** Custom team favoriting and feed filtering.## Project Structure
- `backend/`: FastAPI REST API, Redis caching layer, PostgreSQL data models, external API ingestion.
- `frontend/`: Dashboard UI and team profile views.
